# تاريخ الوطن العربي خلال ١٤ قرنًا

مخطط زمني تفاعلي للدول والأسر الحاكمة في ٢١ قطرًا عربيًا من الهجرة (١هـ / ٦٢٢م) حتى ١٤٣١هـ / ٢٠١٠م.

- `index.html`: المخطط الزمني الرئيسي. كل خانة فيه رابط إلى صفحة الحقبة في ذلك القطر.
- `p/`: صفحة لكل حقبة في كل قطر (الاسم بصيغة `رمز-القطر-سنة-البداية.html`)، فيها نبذة تاريخية، والحقبة السابقة والتالية، وما كان يحكم الأقطار الأخرى في الفترة نفسها.

الموقع ثابت بالكامل (HTML وCSS وJavaScript)، ويُنشر عبر GitHub Pages دون أي خطوة بناء.
